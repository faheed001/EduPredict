# EduPredict 3.0 — Data Dictionary

| Feature | Meaning | Expected range/type |
|---|---|---|
| attendance_percentage | Student attendance percentage | 0–100 |
| study_hours_per_week | Approximate focused study hours per week | 0–80 |
| previous_exam_score | Previous exam score | 0–100 |
| assignment_score | Assignment performance score | 0–100 |
| internal_assessment_score | Internal assessment score | 0–100 |
| extracurricular_activities | Indicator for extracurricular participation | 0/1 |
| parental_support | Encoded support level | 0–2 |
| sleep_hours | Approximate sleep hours | 0–14 |

The dataset bundled with the project is synthetic and intended for academic demonstration/testing.
