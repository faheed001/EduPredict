# Contributing

Contributions are welcome for educational and software-engineering improvements.

## Workflow
1. Fork the repository.
2. Create a feature branch.
3. Make a focused change.
4. Run the automated tests.
5. Run `python tools/audit_project.py`.
6. Update documentation when behavior changes.
7. Open a pull request with a clear description.

## Rules
- Do not commit secrets or real student data.
- Keep synthetic/demo data clearly labelled.
- Prefer small, reviewable changes.
- Add tests for new backend behavior where practical.
