# Changelog

## 3.0.0 - 2026

### Added
- Flask web application with student and teacher roles.
- SQLite persistence for users, student records, performance records, predictions and interventions.
- Student performance prediction.
- At-risk early-warning classification.
- Validation-selected Random Forest + Gradient Boosting ensemble.
- K-Means learning profiles.
- Isolation Forest anomaly detection.
- Feature importance and model analytics.
- Personalized recommendations and study planning.
- Prediction history and teacher intervention tracking.
- CSV export and JSON APIs.
- What-if prediction endpoint.
- Integrated **EduPredict Assistant** for basic, intermediate and system-specific questions.
- Functional tests and project audit tooling.
- Security headers, CSRF controls and role protection.

### Documentation
- Architecture, API, model card, user guide, developer guide and viva preparation documentation.
